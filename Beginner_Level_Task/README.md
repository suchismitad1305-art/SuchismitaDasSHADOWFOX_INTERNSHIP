## About

This repository contains a beginner-friendly implementation of the Data Visualization Using Python task. It demonstrates common visualizations using **Matplotlib** and **Seaborn**.

The project follows the uploaded internship report's scope and examples rather than introducing advanced machine-learning or statistical methods.

- Line Chart
- Bar Chart
- Histogram
- Scatter Plot
- Pie Chart

### Seaborn
- Line Plot
- Bar Plot
- Histogram
- Scatter Plot
- Box Plot
- Count Plot

## Setup

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Install packages

```bash
pip install -r requirements.txt
```

## Run the project

From the repository root:

```bash
python src/visualizations.py
```

The generated charts will appear in `outputs/`.

## Run the notebook

```bash
jupyter notebook notebooks/data_visualization_beginner.ipynb
```

Open `data_visualization_beginner.ipynb` and run the cells from top to bottom.

## Beginner-level learning goals

- Understand why data visualization is useful.
- Learn the basic syntax of Matplotlib.
- Learn the basic syntax of Seaborn.
- Practice line, bar, histogram, scatter, pie, box and count plots.
- Learn to label and save visualizations.
- Compare the general roles of Matplotlib and Seaborn.
