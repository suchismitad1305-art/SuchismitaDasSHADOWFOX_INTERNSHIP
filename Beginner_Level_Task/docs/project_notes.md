# Project Notes

## Source basis

This project is based on the uploaded **Data Visualization Using Python** internship report.

The report introduces data visualization and demonstrates Matplotlib and Seaborn through basic examples. The implementation here follows that same beginner-level scope.

## Matplotlib topics

- Line chart
- Bar chart
- Histogram
- Scatter plot
- Pie chart

## Seaborn topics

- Line plot
- Bar plot
- Histogram
- Scatter plot
- Box plot
- Count plot

## Matplotlib vs Seaborn

The report describes Matplotlib as a lower-level plotting library with detailed control over graphic elements, while Seaborn provides a higher-level statistical visualization interface with concise plotting functions and integration with Pandas.

## Beginner learning outcomes

After completing this project, a learner should be able to:

1. Import common Python visualization libraries.
2. Create basic charts.
3. Add titles and axis labels.
4. Work with simple lists and Pandas DataFrames.
5. Save plots as image files.
6. Recognize common uses of different chart types.
